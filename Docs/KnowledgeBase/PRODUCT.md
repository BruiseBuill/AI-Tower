# 产品定义

## 已确认

- 游戏类型：俯视角、反向塔防、轻策略。
- 玩家身份：进攻者；防御塔和地形构成需要突破的防守系统。
- 核心交互：点击、滑动及少量 UI 操作，整体操作量很轻。
- 首发平台：Android。
- 开发环境：Windows 编辑器，以鼠标模拟单指触屏操作。
- 游戏模式：单机。
- 语言：仅中文。
- 项目周期：长期迭代，而非一次性原型。
- 内容目标：约十余关，从教学和少量塔型逐步发展到复杂地形和复杂防御塔。
- 成长：存在跨关卡或局内成长体系，具体结构待确认。
- 存档：需要本地存档系统。
- 验收：由用户亲自试玩验收，不要求截图或自动化测试。
- 内容资产：正式美术、音乐和语音由用户提供；AI 开发时使用基础占位内容。
- 第三方插件：现有插件许可已由用户确认，不再进行许可检查。
- 基础框架：`BaseFramework` 必须保留，后续允许逐步修改。

## 体验原则

- 决策重于操作速度：难点应来自路径、时机、资源分配和阵容选择，而非高频点击。
- 手机优先：信息清晰、触控目标足够大，重要操作不依赖悬停、右键或键盘。
- 渐进教学：首关只介绍最少概念，后续关卡逐项引入新塔、地形或成长机制。
- 快速理解反馈：部署、受击、死亡、资源变化、路径受阻和胜负原因必须清楚。
- 可扩展内容：新增单位、塔、关卡和成长项应主要通过数据与资源配置完成。

## 暂不纳入范围

- 联机、账号、排行榜和社交系统。
- 多语言。
- 广告、内购或其他商业化功能。
- 用户尚未要求的复杂跨平台支持。
- 最终美术、音乐和语音制作。

以上“暂不纳入”不是永久否决；只有用户明确提出时才进入计划。
